## 目視

- 8 枚とも、写っているのは Inkdrop の窓（「Learn」ノートブックのチュートリアルのノート）だけ。ほかの窓や個人の内容は写っていない。ユーザーには、撮影の前にデスクトップのほかのアプリを隠してもらった。
- 行番号とアクティブ行は、全部の画像に出ている。
- **状態の持ち越し**:
  - 検索の一致の強調（`.cm-searchMatch`）が、検索の状態（SD の 2 枚目）のあとも残っていた。そのため、SD のコードブロック、KD の不透明のアクティブ行・検索・コードブロックの画像にも、一致の強調が写っている。
  - KD の「選択のないアクティブ行」（不透明）は、検索の一致が見える状態で撮れている。
  - acrylic の 2 枚は、再起動の後なので、一致の強調はない。
  - 判定（アクティブ行・ガターの Computed Style）は、この持ち越しの影響を受けない。ただし、画像を状態 1 の見え方の基準にするときは、この点に注意が要る。
