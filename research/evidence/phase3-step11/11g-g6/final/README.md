# G6 V-35: Inkdrop 6.2.0 の参考画像（確定版、C6、2026-10-25）

[14](../../../../14-implementation-plan.md) §6.117 の証拠。V-35 の視覚的な参考画像には、ここの 8 枚を使う。`c3/` は状態の持ち越しがあるため、使わない。

- **撮影の条件**:
  - 撮ったもの: Inkdrop 6.2.0（本番のアカウント）、テーマは Solarized Dark 2.2.1 と Kanagawa Dragon 1.2.1。チュートリアルのノート「Basic writing and formatting syntax」。
  - 窓: 1200×700pt を (400, 250) に置き、灰色の背景の窓をその後ろに置いた。
  - 撮り方: `screencapture -R400,250,1200,700`。画像は 2400×1400 で、devicePixelRatio は 2。
  - 撮る前に、ユーザーがデスクトップのほかのアプリを隠した。
- `screenshots/`: 8 枚。
  - 不透明: アクティブ行、検索の一致、コードブロック。
  - acrylic: アクティブ行。
  - 上の 4 枚を、両テーマで撮った。
- `measurements/`: Computed Style、層の順、窓、状態。ノートの ID・リビジョン・本文のハッシュは含めない。
- `judge.json`: COMPLETE。PASS 2（両テーマのアクティブ行が V-22 と一致）、RECORD 6。
- `runs.json`: C4〜C6 の要約。いつ撮ったか、ノートが変わっていないこと、復元の結果（どれも RESTORED）。
- `run-c4.log`〜`run-c6.log`: 実行の記録（パスは短くした）。
