[14](../../../14-implementation-plan.md) §6.187 の証拠。ユーザーの許可（隔離 Obsidian のみ。通常の Obsidian・Vault・本番 Inkdrop・iPhone には触れない）のあと、`../11v-overlay-corner-trial/` の 3 規則を、SD・KD の「最終の CSS」と「試験の CSS」で比べた。**製品の CSS・基準・検査は変えていない。**

## 計算値（`trial-*.json`、`trial2-*.json`。SD・KD で同じ）

| 対象 | 最終（今） | 試験 | Inkdrop 6.3.0 |
|---|---|---|---|
| コマンドパレットの外枠 | 12px | 24px | 24px |
| パレットの行 | 4px | 7px | 7px |
| メニューの外枠 | 8px | 15px | 15px |

- 到達範囲: `.prompt` はコマンドパレットとクイックスイッチャー（どちらも 24 / 7px）。`.menu` はファイル・エディタ・タブのコンテキストメニューとステータスバーのメニュー（8 → 15px）。**変化なし**: Graph のコントロール（8px）、削除確認のモーダル（24px）、通知（8px）。終了後に残った `.prompt` / `.menu` / `.modal` は 0。
- クリッピング: パレットの先頭行と hover 行、メニューの先頭・末尾項目の hover で、項目の四隅は外枠の外に出ない（`cornersOutsideMenu` 0）。メニューは窓の右下の端でも窓の内に収まった（`insideViewport` true）。
- 操作: ArrowDown で選択が移る、入力で絞り込み、Esc で閉じる。最終と試験で同じ。
- 画像（`shots/`）: パレット、メニューの先頭・末尾の hover、窓の端のメニュー。目で見て、角の欠け・はみ出しはなかった（確認したのは SD のパレットと窓の端のメニュー、KD の末尾 hover。残りは計算値で確認）。ページの画素だけ（acrylic・窓の影は含まれない）。
