# G5 v2 撮り直しの目視

`*-v2-regions.png` と `*-v2-top.png` は `python3 -I tests/visual/g5-overlay.py <撮影の出力> <この場所>` で作った。`review-montage.png` は 8 枚を縮小して並べたもの。

- マゼンタ: `pair.titlebar`（x 722.38〜906pt、y 4〜26pt）と区画の線
- 緑: `pair.tab`（同じ列、y 34〜66pt）と区画の線
- 水色: v1 の左のタブ帯（診断用）

## 目視（8 枚すべて）

- 8 枚すべてに隔離インスタンスの窓が写っており、窓は撮影の矩形と一致している。通知・ほかの窓・個人の情報はない。
- 前回の 1 枚目（after・SD・translucent）も、今回は窓が写っている（`focused: true`）。
- タイトルの文字は 8 枚とも x 482〜717pt にあり、測定の領域（722.38pt から）に入っていない。
- 中央のタブ帯の右の「∨」のボタンは 8 枚とも x 913〜922pt にあり、領域（906pt まで）に入っていない。
- 窓のボタン（左端）と右上の丸い角は、領域から外れている。
- 2 つの帯は同じ列を測っている。
