# G8: Inkdrop 6.3.0 と Obsidian 1.14.5 のオーバーレイの比較（2026-11-03）

[14](../../../14-implementation-plan.md) §6.185 の証拠。ユーザーの「準備できた」のあと、本番の Inkdrop（`inkdrop-production.sh` で控え・復元）と、隔離した Obsidian（1.14.5 / Electron 43.8.3、`52434a5` の 4 ノートの撮影専用 Vault）で、**同じ種類のオーバーレイを両アプリで開き、見た目と計算値を比べた。製品の CSS・基準・検査は変えていない。** Inkdrop 側は 6.3.0 で、**6.2.0 での確認ではない**（補助の資料。§6.180 の A/B/C 分類は後述）。

## 方法

- 画像は、アプリのページの画素を CDP の `Page.captureScreenshot` で取った（macOS の画面は撮っていない。両アプリとも窓 1200×700。設定のウィンドウは各アプリの別窓）。計算値は、各要素の `getComputedStyle`。
- 状態は、データを変えずに開いて閉じるだけ。Inkdrop: コマンドパレット（`core:toggle-telescope`）、状態のメニュー（ノートの見出しの Status のドロップダウンを、実際のマウスのクリックで開く）、新しいノートブックのモーダル（`core:new-notebook`、Esc で閉じる。作成していない）、通知（`inkdrop.notifications.addInfo`、閉じた）、環境設定（General。アカウントの画面は避けた）。Obsidian: コマンドパレット、ファイルのコンテキストメニュー（`nativeMenus` 無効の撮影専用 Vault。メニューの先頭に実際のポインタを置いた）、ファイル削除の確認のモーダル（Esc で閉じる。削除していない）、通知（`Notice`）、設定（外観）。
- ボタンの状態（通常、hover、押下、キーボードの focus）: 環境設定・設定のウィンドウのボタン 1 つで、実際のポインタとキーで測った（クリックは発生させていない）。
- スリープの防止: ユーザーの依頼で、撮影の間 `caffeinate -d -i -s` を動かし、終わって止めた。`pmset` の設定は変えていない（前後の出力が同じ。`pmset-before.txt`・`pmset-after.txt`）。

## 結果（`review/` の左が Inkdrop、右が Obsidian。数値は `compare.txt`、SD と KD の両方）

色と形で、一致するもの・違うものを分ける。

| UI | 一致している点 | 違う点（SD。KD も同じ構造） |
|---|---|---|
| モーダル | 背景色（`rgb(0,33,41)`）、角丸 24px、ボタンの背景 | Inkdrop は見出しの帯（背景 `rgb(0,45,56)`）と、枠付きの入力欄（角丸 15px、アクセントの枠）、主ボタンが青。Obsidian は見出しの帯・入力欄がない（今回の削除の確認の内容の違い）、主ボタンは赤（削除）。余白（Inkdrop の見出し 14×17px）、ボタンの高さ（33 対 30px）、枠（Obsidian は 1px の枠） |
| コマンドパレット | 選択行の背景（`rgba(255,255,255,0.08)`）、文字色 | 角丸（24 対 12px）、影（Inkdrop は `0 10px 30px` の濃い 1 層、Obsidian は薄い多層）、選択行の角丸（7 対 4px）、行の高さ（37 対 32px）、余白（8×10 対 6×12px）。選択行の文字は Inkdrop がアクセント色、Obsidian は通常の色 |
| メニュー | 枠の太さ、文字色 | **背景色**（Inkdrop の in-app のドロップダウン `rgb(0,33,41)` 対 Obsidian のメニュー `rgb(0,20,26)`。Obsidian のほうが暗い）、角丸（15 対 8px）、影、項目の余白（11×16 対 4×8px）、選択項目の文字（Inkdrop はアクセント色） |
| 通知 | 背景色（`rgba(0,20,26,0.8)`） | 角丸（15 対 8px）、影（Inkdrop あり、Obsidian なし）、大きさ（420×69 対 160×33px）、題の文字（Inkdrop はアクセント色で太字、Obsidian は白の 1 行）。Obsidian は題と本文の構造がない |
| 環境設定・設定 | 地の色、ボタンの背景、ドロップダウンの背景 | 角丸（ボタン・ドロップダウンは 15 対 8px）、ボタンの縁の内側の線（Inkdrop は 1px の白 15%）、ボタンの文字（Inkdrop は不透明度 0.6、hover で 0.8、押下で 0.9。Obsidian は固定）、選択中の項目（Inkdrop は不透明の `rgb(52,66,86)`、Obsidian は `rgba(71,173,245,0.2)` で角丸 8px） |
| ボタンの状態 | 通常・hover の背景は一致（SD `rgba(0,45,56,0.7)` / `rgba(7,53,65,0.7)`、KD `rgb(39,38,38)` / `rgb(58,57,54)`） | **押下**: Inkdrop は専用の色（SD 不透明の `rgb(0,45,56)`）、Obsidian は hover と同じ（押下の状態がない）。**focus**: Inkdrop は 2px のアウトライン（アクセントの 30%）、Obsidian は 3px のボックスシャドウ（アクセントの 60〜70%） |

視覚で見えた傾向: **色（地、文字の濃さ、アクセント）は両テーマで近く、形（角丸・影・余白・大きさ）が系統的に違う**。Inkdrop は大きめの角丸（15〜24px）と余白、Obsidian は小さめの角丸（4〜12px）と詰めた余白。これは G8 が求めた「色以外の差」の実測。

## 6.2.0・6.3.0 の差の扱い（§6.180 の分類）

- **A（静的な CSS の規則に差がない）**: メニュー、モーダル、コマンドパレット、通知、環境設定のフォーム、ボタンの通常・hover の背景。形の差は、6.3.0 の実測で、6.2.0 でも同じとは断定しない。
- **B（6.3.0 で変わったことが分かっている）**: 今回の対象にはない（インラインコードのコピーボタン、幅広い表）。
- **C（版の間の差が不明）**: ボタンの押下・focus の状態（同梱 CSS の差がある down・active の変数。SD・KD のパレットにも対応表にもない）、JavaScript による動き。

## 比べていないこと

- ツールチップ（Inkdrop のツールバーのアイコンに、`title` の吹き出しを出せなかった）、Obsidian の Popover（Inkdrop に対応が確認できない）、OS のネイティブのメニュー（macOS の既定）、translucent の窓の影、入力欄の focus・エラーの状態、フォームの無効の状態。
- Inkdrop 6.2.0 での確認（実行環境がない）。

## 後片付け

- Inkdrop: 通常の終了 → `config.json` を戻し → 通常の起動（`RESTORED`、9334 閉）。強制終了なし。ノートの ID・リビジョン・`updatedAt`・題名は前後で同じ。テーマは作業前の `solarized-dark` に戻した。環境設定の窓は開いて閉じた（隠れた窓が残るのは Inkdrop の仕様）。
- Obsidian: 隔離インスタンスを停止（9333 閉）、撮影専用 Vault のノートは前後で同じ、LaunchServices は元の出力。
- 画像: 切り出し 16 枚と、環境設定 4 枚を、並べた比較 10 枚の中で見て確認した（Inkdrop の環境設定の画像は、並べるとき 736 px から 700 px に縮めた。個別のファイルを 1 枚ずつ開いて見たわけではない）。コミットしていない、窓全体の画像（状態ごとの全体の画面）は見ていない。対象のアプリのページだけで、ほかの窓は写らない（ページの画素を取るため）。
- **個人の内容について**: 探索のとき、Inkdrop の環境設定の窓が Account の画面で開き、ユーザーの名前と登録日が写った画像が 1 枚、作業用の一時領域に保存された。コミットはしておらず、その場で削除した。以後の撮影は、General の画面（Inbox、更新、開発者モードの設定だけ）に限った。コミットした画像に個人の内容はない。
- **画像の限界**: ページの画素なので、窓の背後の半透明（acrylic）や OS の窓の影は含まれない。Inkdrop のサイドバーなどの半透明の面は、画像では明るい灰色に見える（実際の見た目ではない）。オーバーレイ自体の形・色・影の比較には使えるが、窓全体の見た目の比較には使えない。
